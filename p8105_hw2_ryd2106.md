The resultant dataset contains 19 different variables. Of which, the
following are character types: line, station_name, each of the 11
routes, vending, and entrance_type. The numeric vectors are
station_latitude, and station_longitude. The logical vectors are: entry,
and ada. So far, I have tidied the dataset with the janitor function. I
then, converted the Yes/No character values in the entry vector to
TRUE/FALSE logical values. To ensure all routes were character values
and not partially numeric, I converted their value types to character
ones.Finally, I mutated this entry vector type from character to
logical. The final data set is a (1868 x 19) dataset. This dataset is
not tidy since the route data is spread over multiple columns when it is
technically a single variable. To fix this, the route data should be
condensed into two variable columns. One stating the number of routes
passing through the station, the other stating what these routes are.
Additionally, the station name is separated into two columns and should
be combined into one. Finally there are many repeats of the same entry.
To fix this the distinct function should be applied to get only one true
entry value.

``` r
#Numer of unique stations
combined_stations = unite(train_data, station_united, line, station_name) 
distinct_stations = combined_stations |> 
  unique()

ada_distinct = distinct_stations |> 
  filter(ada == TRUE) |> 
  nrow()

#Portion of stations entrances / exists without vending allow entrance
entrance_vending = combined_stations |> 
  distinct(station_united, entry, vending) |> 
  mutate(
   vending = case_match( 
     vending,
      "YES" ~ 1,
      "NO"  ~ 0)) |> 
  mutate(
    entry = as.numeric(entry)) 
#Numeric sum of entry data
entry_count = combined_stations |>
  pull(entry) |> 
  sum(na.rm = TRUE) 
#Numeric sum of vending

  mutate(
    vending = case_match(
      vending,
      1 ~ 1,
      0 ~ 0,
      NaN ~ 0)) |> 
  pull(vending) |> 
  sum(na.rm = TRUE) 

portion_sum =  entry_count/ vending_count
```

This data set was tidied and cleaned through the following ways. After
loading the dataset in, I skipped the first line to avoid confusing
column labels. I then converted all NA synonyms to the na symbol.
Applying tidy converted the column labels into readable snakecase. To
ensure that the sex and apoe4 columns were not numeric I converted them
to factor data types. Participants with MCI at the start of the study
would mess up the results. To avoid this I filtered out these
individuals.

The resultant data set disseminates the id, current age, sex, education
apoe4 carrier status, and the age at onset. The apoe4 column illustrates
which participants are carriers of the APOE4 gene. Those that are
carriers are marked as 1, while non-carriers are 0. The data set is a
479, 6 table. While there were 483 participants who initially signed up,
only 479 actually participated. Of this set, only 93 participants
